# Data Warehouse Learning Project

## Overview

This repository contains my implementation of an end-to-end data warehouse built while following the YouTube walkthrough **"Building a Full Data Warehouse"** by **Data with Baraa**.

The goal of this project is to gain hands-on experience with modern data engineering concepts, including data warehousing, ETL processes, data modeling, and SQL development. Throughout the project, I focused on understanding each step rather than simply reproducing the code.

## Learning Objectives

- Understand the architecture of a modern data warehouse
- Learn the ETL (Extract, Transform, Load) process
- Practice SQL for data transformation and analysis
- Design and implement fact and dimension tables
- Gain experience with dimensional modeling and the Star Schema
- Improve data engineering best practices

## Data Warehouse Architecture

The warehouse follows a dimensional model consisting of:

- Fact Tables
- Dimension Tables
- Star Schema Design

The ETL process extracts raw data, transforms it into a clean and structured format, and loads it into the warehouse for analytical querying.
